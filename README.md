# Landeck a centralized controller and monitor for home servers and automation

## Features planned:
1. Ability to connect docker containers, individual apps and scripts to the frontend ui
2. Monitor server resources like ram cpu disk usage etc
3. Turn off and on containers
4. Control apps using the frontend and parameters needed values according to user needs

## Tech Stack:
### Backend: 
Python, Fastapi
### Frontend:
Javascript, react, html, css
